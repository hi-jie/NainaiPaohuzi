# 麻雀牌玩法规则（已确认）

适用于本项目的「麻雀牌」玩法，按家里确认的口径执行。

## 和公开玩法对比

公开资料中，「麻雀」也常指筒、索、万麻将。香港麻将游戏平台公开的玩法同样只吃上家打出的牌，并区分点炮和自摸，但开局通常是十三张手牌，可以碰杠，吃牌后要亮出牌组。你的版本是庄家十一张、闲家十张，只能暗吃，胡牌必须是三顺一对。[香港麻将平台玩法说明](https://play.agames.hk/mobile/mjweb/explanation_06.html)

黄金岛公开的湖南跑胡子规则使用大小字各四份，共八十张，承认同字号连续牌和二七十，也有碰、比、偎、提、跑及胡息。你的版本保留连续顺子和二七十，另纳入一五十，吃牌留在手里，不按胡息结算。[黄金岛跑胡子规则](https://www.80166.com/guide/rule/phz.html)

公开检索未找到能核实这十条的珠晖区皇田村成文规则。以上资料仅用于对比，地方细节按本稿和家里确认的口径处理。

## 开局

- 每局 **3–5 人**，行牌按**逆时针**轮转。按行牌顺序，自己之前一位是上家，之后一位是下家。
- 使用 **80 张**字牌，小字「一至十」和大字「壹至拾」，每种四张。
- 首局随机定庄。庄家抓 **11 张**，每名闲家抓 **10 张**。庄家先行，起手能胡可直接按自摸结算，否则先打一张。3、4、5 人开局后，牌墩分别剩 **49、39、29 张**。

## 摸、吃、打

1. **摸牌**：轮到自己时从牌墩摸一张，直接收入手牌。能胡则可报胡，否则打出一张。摸出的牌在手里，其他玩家等到它被打出后才有机会接牌。
2. **暗吃**：只能吃上家刚打出的牌，无须凑顺子。自己以前打过同名牌也能吃。吃进的牌直接收入手牌，整手可重新组合，随后必须打一张，可以立刻把刚吃的牌原样打回。
3. **出牌**：摸或吃后有 11 张，打一张后回到 10 张。每次出牌先处理接炮。无人接炮后，由出牌人的下家决定是否吃。下家不吃时，该牌进弃牌区，下家摸牌。
4. **无臭张**：上一轮放过的牌，如果上家下一轮又打出，仍可吃这一次打出的牌。已经进弃牌堆的牌不能再吃。行牌操作只有摸、吃、打、胡。
5. **黄庄**：牌墩摸空后，继续按正常顺序打、胡、吃。吃后打出的牌也继续受理胡、吃。轮到有人需要摸牌却无牌可摸时黄庄，本局不计分。

## 胡牌

胡牌的 **11 张**必须能完整拆成**三个顺子和一个对子**。只要有一种合法拆法即可。刻子和杂刻（大小字混搭的同数牌组）不能作为胡牌牌组。

| 牌组 | 规则 | 例子 |
| --- | --- | --- |
| 普通顺子 | 同字号的三张连续数字 | 一二三、陆柒捌 |
| 一五十 | 每局允许，同字号的一、五、十 | 一五十、壹伍拾 |
| 二七十 | 同字号的二、七、十 | 二七十、贰柒拾 |
| 对子 | 两张完全同名的牌 | 四四、玖玖 |

例如「一二三／二七十／壹伍拾／四四」可以胡；「一一一／二七十／壹伍拾／四四」里的三个「一」无法另拆成合法顺子，因此不能胡。

- **自摸**：自己从牌墩摸进一张后满足胡牌条件。庄家起手 11 张可直接胡，结算按自摸计。
- **接炮胡**：任一对手打出的牌使自己满足胡牌条件。上家打出的牌直接凑成胡牌也属于接炮。
- **一炮只胡一家**：从放炮人的下家起按逆时针依次询问可胡者。可以选择过，过后顺延给下一位可胡者，一旦有人接炮即结束。比如甲出牌，乙不能胡，丙和丁能胡，则先问丙，丙过后再问丁。
- **过胡**：放过接炮胡后，自己实际摸牌或吃牌前，所有接炮机会都受限，包括不同名的牌。只记录实际收到接炮选项并点「过」的人，每局重新发牌时清除记录。
- **解除过胡**：从牌墩摸到能胡的牌，可以当场自摸。暗吃也会清除过胡记录，吃后仍须先出一张，再受理之后的接炮。用上家打出的同一张牌当场胡属于接炮，必须在该张牌的接炮阶段决定。

## 结算

**胡牌不算胡息，每份 1 分**。赢家加分等于其他玩家的合计扣分。

| 情况 | 谁扣分 | 赢家加分 |
| --- | --- | --- |
| 接炮胡 | 放炮人扣 1 分 | 1 分 |
| 自摸胡 | 其他玩家每人扣 1 分 | 3 人局加 2 分、4 人局加 3 分、5 人局加 4 分 |
| 黄庄 | 无 | 0 分 |

有人胡牌时，胡牌者坐下一局的庄。黄庄时，本局庄家的下家坐下一局的庄。

## 实现时核对

- 发牌后检查 3、4、5 人的手牌张数、牌墩张数及逆时针顺序。
- 验证庄家起手胡、自摸、接炮、多人接炮时顺延，以及所有人过胡后转入下家的吃牌选择。
- 验证暗吃只取上家当前打出的那张，吃进后该牌只计入手牌一次。下家选择不吃后，弃牌才入弃牌区，并进入下家的摸牌步骤。
- 用「过胡五、接炮六」验证不同名牌也受限，再验证实际摸到胡牌张可自摸、吃牌清除限制但必须先出牌。
- 验证牌墩已空时可连续吃打，直到需要摸牌才黄庄。覆盖黄庄换庄、胡牌换庄，以及 3 至 5 人的分数守恒。
