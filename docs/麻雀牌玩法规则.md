# 麻雀牌玩法规则（确认稿）

适用于本项目新增的字牌玩法。下文以你提供的十条为准，尚未确定的细节单列。

## 和公开玩法对比

公开资料中，「麻雀」也常指筒、索、万麻将。香港麻将游戏平台公开的玩法同样只吃上家打出的牌，并区分点炮和自摸，但开局通常是十三张手牌，可以碰杠，吃牌后要亮出牌组。你的版本是庄家十一张、闲家十张，只能暗吃，胡牌必须是三顺一对。[香港麻将平台玩法说明](https://play.agames.hk/mobile/mjweb/explanation_06.html)

黄金岛公开的湖南跑胡子规则使用大小字各四份，共八十张，承认同字号连续牌和二七十，也有碰、比、偎、提、跑及胡息。你的版本保留连续顺子和二七十，另纳入一五十，吃牌留在手里，不按胡息结算。[黄金岛跑胡子规则](https://www.80166.com/guide/rule/phz.html)

公开检索未找到能核实这十条的珠晖区皇田村成文规则。以上资料仅用于对比，地方细节按本稿和家里确认的口径处理。

## 开局

- 每局 **3–5 人**，行牌按**逆时针**轮转。按行牌顺序，自己之前一位是上家，之后一位是下家。
- 庄家抓 **11 张**，每名闲家抓 **10 张**。暂按庄家先行，起手能否直接胡见待确认项。
- 牌具暂按项目现有的 80 张湖南字牌，小字「一至十」和大字「壹至拾」，每种四张。如果沿用这副牌，3、4、5 人开局后，牌墩分别剩 **49、39、29 张**。

## 摸、吃、打

1. **摸牌**：轮到自己时从牌墩摸一张，直接收入手牌。能胡则可报胡，否则打出一张。摸出的牌在手里，其他玩家等到它被打出后才有机会接牌。
2. **暗吃**：只能吃上家刚打出的牌。按通常的吃牌定义，暂按该牌能和手里两张牌组成允许的顺子才可吃。吃进的牌直接收入手牌，整组留在手里；未胡时打出一张。吃牌资格、吃进后能否拆组等细节见待确认项。
3. **出牌**：摸或吃后有 11 张，打一张后回到 10 张。按本稿暂定顺序，一张打出的牌先处理胡牌，再由出牌人的下家决定是否吃。无人胡、下家不吃时，该牌进弃牌区，下家摸牌。
4. **无臭张**：上一轮放过的牌，如果上家下一轮又打出，仍可按当时的手牌重新判断能否吃。没有碰牌；暂按本玩法也没有偎、提、跑或比牌。

## 胡牌

胡牌的 **11 张**必须能完整拆成**三个顺子和一个对子**。只要有一种合法拆法即可。刻子和杂刻（大小字混搭的同数牌组）不能作为胡牌牌组。

| 牌组 | 暂定口径 | 例子 |
| --- | --- | --- |
| 普通顺子 | 同字号的三张连续数字 | 一二三、陆柒捌 |
| 一五十 | 同字号的一、五、十 | 一五十、壹伍拾 |
| 二七十 | 同字号的二、七、十 | 二七十、贰柒拾 |
| 对子 | 两张完全同名的牌 | 四四、玖玖 |

例如「一二三／二七十／壹伍拾／四四」可以胡；「一一一／二七十／壹伍拾／四四」里的三个「一」无法另拆成合法顺子，因此不能胡。

- **自摸**：自己从牌墩摸进的牌使手牌满足胡牌条件。
- **放炮胡**：别人打出的牌使自己满足胡牌条件。吃只限上家，放炮胡暂按任一对手打出的牌都可接胡；上家打出的牌如果直接凑成胡牌，按放炮胡处理。
- **一炮只胡一家**：从放炮人的下家起按逆时针查找，第一位满足胡牌条件的人优先。例：顺序为甲 → 乙 → 丙 → 丁 → 甲，甲出牌，丙、丁都能胡且乙不能胡，则丙优先。优先者是否可放弃、放弃后是否顺延，待确认。

## 结算

**胡牌不算胡息**。以一份为单位，赢家收入等于其他玩家合计支出。

| 情况 | 谁付 | 赢家收入 |
| --- | --- | --- |
| 放炮胡 | 放炮人付一份，其余玩家不付 | 一份 |
| 自摸胡 | 每名其他玩家各付一份 | 3 人局两份、4 人局三份、5 人局四份 |

## 请确认的细节

1. **牌具与顺子**：是否用完整 80 张字牌？连续顺子、一五十、二七十都要求同为大字或同为小字吗？一五十是否每局都允许？
2. **暗吃限制**：吃进时是否一定要用手里两张凑顺子？吃进后，这三张能否拆开重新组合？能否立刻打回刚吃的同一张？自己之前打过同名牌时，之后还能不能吃？
3. **胡牌顺序**：胡是否先于吃？能胡时是否可以过？多人能胡时，如果最靠前的人选择过，是否顺延给下一位？是否可以胡自己之前过过的同名牌？
4. **起手与牌墩**：庄家起手 11 张能胡时能否直接胡，按几份结算？牌墩摸完是否直接黄庄、不计分？最后一张摸完后打出的牌是否仍可胡或吃？
5. **下一局与积分**：首局怎么定庄，胡牌或黄庄后谁坐庄？一份折算多少游戏积分，是否所有胡牌都按固定一份计算？
