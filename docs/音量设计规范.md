# 衡阳跑胡子音量设计规范

报牌、吃、碰等方言语音传达牌局信息。默认音量以手机扬声器能听清这些语音为准，音乐作为背景。响度用 LUFS 表示，真峰值用 dBTP 表示，分别用来检查听感一致性和混音余量。测量方法参考 [ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I)。

PlayStation 的建议针对代表性整段游戏混音。家用平台参考 −24 ±2 LKFS，便携平台参考 −18 ±2 LKFS，真峰值不超过 −1 dBTP。建议采样至少 30 分钟。这些值供本项目评估整局混音时参考，短报牌录音按下表单独验收。[Sony ASWG-R001 v1.2](https://github.com/Sony-ASWG/Loudness/blob/main/ASWG-R001%20v1.2.pdf)

Xbox 无障碍指南建议音乐和语音等类别能够独立调节或静音，以便玩家听清关键提示。首页和牌局的两个音量滑杆共享同一份本地设置。[Xbox Accessibility Guideline 105](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/105)

| 项目 | 本游戏采用的值 |
| --- | --- |
| 方言素材 | 每段 −14 ±0.5 LUFS，真峰值 ≤ −3.5 dBTP。统一用 `node scripts/process-voices.mjs` 从原录音生成 |
| 游戏音效 | 方言与通用音效共用开关和 0–100% 滑杆，默认 100% |
| 背景音乐 | 默认 20%，独立开关和 0–100% 滑杆。20% 对应约 −14 dB 的播放增益 |
| 默认混音 | 目标真峰值 ≤ −1 dBTP。方言与配乐按素材的最大真峰叠加估算，峰值上界约 −1.35 dBTP |

手机验收时，固定系统媒体音量，用默认滑杆播放四首配乐，覆盖摸牌、出牌、吃、碰、跑和胡。听报牌和动作能否在配乐中辨认，再分别拉动两条滑杆，确认只改变对应类别，关掉再打开游戏后保留设置。加入新配乐时重新测文件响度和真峰值。验收整局混音时，录制实际输出并测量响度和真峰值，覆盖默认设置及高音乐音量的场景。当前的 −1.35 dBTP 是素材计算值，整局录音和手机实听待验收。
