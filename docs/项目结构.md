# 单机衡阳跑胡子项目结构

网页试玩、本地预览和 Android APK 共用 `android/app/src/main/assets/www/`。GitHub Pages 的部署工作流直接发布这个目录，Android 通过 `WebViewAssetLoader` 从 APK 加载同一份网页、字体和音频。

## 仓库目录

| 路径 | 用途 |
| --- | --- |
| [README.md](../README.md) | 安装、玩法和发布入口 |
| [docs/](./) | 玩法规则、设计记录和音量规范 |
| [android/](../android/) | Android 工程、Gradle Wrapper 和应用资源 |
| [scripts/](../scripts/) | 更新音乐列表、处理方言录音 |
| [tests/](../tests/) | 牌型、计分、牌局流程和音效测试 |
| [Pages 工作流](../.github/workflows/pages.yml) | 推送到 `main` 时更新曲目列表并部署网页 |

## Android 和网页源码

`android/app/src/main/` 下的 `java/` 放置 WebView Activity，`res/` 放置应用名称、图标和主题。应用入口和横屏配置位于 `AndroidManifest.xml`。SDK、版本号和正式签名配置位于 [android/app/build.gradle](../android/app/build.gradle)。

下表的路径相对于 [assets/www/](../android/app/src/main/assets/www/)。

| 路径 | 用途 |
| --- | --- |
| `index.html`、`css/app.css`、`js/main.mjs` | 页面结构、样式和游戏入口 |
| `js/rules/` | 玩法配置、牌型、胡息、胡牌和计分 |
| `js/game/`、`js/ai/player.mjs` | 发牌、牌局状态推进和电脑玩家决策 |
| `js/ui/` | 牌桌、手牌拖动、个人页和教程 |
| `js/storage/save.mjs` | 本地积分、设置、个人资料和对局存档 |
| `js/audio/`、`media/audio/` | 音效、方言录音和背景音乐 |
| `media/avatars/`、`media/fonts/` | 牌友头像和牌面字体 |

本地预览和 Android 构建命令见 [README 的开发与维护](../README.md#开发与维护)。在项目根目录运行 `node --test` 可验证游戏规则和对局流程。
